# alejandrosalguero.es

CV/portfolio personal de Alejandro Salguero. Construido con [Astro](https://astro.build)
y [Tailwind CSS](https://tailwindcss.com), desplegado en GitHub Pages.

- 🇪🇸 Español (por defecto): `/`
- 🇬🇧 English: `/en/`

## Desarrollo

```sh
pnpm install
pnpm dev
```

## Build

```sh
pnpm build
pnpm preview
```

[`AGENTS.md`](./AGENTS.md) (enlazado también como `CLAUDE.md`).
